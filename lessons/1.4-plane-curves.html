Goals学习目标Learning goals

  • 隐式：会用 f(x, y) 的正负判断一个点在曲线的里面、外面还是上面；知道直线的隐式方程就是 1.2 课的点积 n · (P − P₀) = 0。
  • 参数式：会写 P(t)，知道 t 像时间：改变 t 的范围和"速度"能控制画出哪一段、从哪里出发、往哪个方向走。
  • 选对表示：知道三种表示各自擅长什么、做不到什么：显式 y = f(x) 一个 x 只有一个 y；隐式擅长判断里外，不擅长造点；参数式擅长造点，不擅长判断里外。
  • Implicit: use the sign of f(x, y) to tell whether a point is inside, outside or on a curve, and see that a line's implicit equation is lesson 1.2's dot product n · (P − P₀) = 0.
  • Parametric: write P(t) and treat t like time: changing its range and "speed" controls which piece gets drawn, where it starts and which way it goes.
  • Pick the right one: know what each form is good and bad at: explicit y = f(x) allows one y per x; implicit is great for inside/outside tests but poor at producing points; parametric produces points easily but is poor at inside/outside tests.

Intuition直觉Intuition

同一个圆，可以用三种方式"告诉"电脑：

You can "tell" a computer about the same circle in three ways:

  • 显式像一张查询表：给我 x，我告诉你 y。y = √(r² − x²) 只给出上半圆，因为一个 x 只能查出一个 y。
  • 隐式像一个检查员：给我一个点，我告诉你它在哪一侧。f(x, y) = x² + y² − r²，负数在里面，正数在外面，0 正好在圆上。但它不会主动告诉你圆上有哪些点。
  • 参数式像一个画笔的动作：随着时间 t 走，笔尖在 P(t) = (r cos 2πt, r sin 2πt)。要多少点就取多少个 t，但它不能直接回答"这个点在不在里面"。
  • Explicit is a lookup table: give me x and I give you y. y = √(r² − x²) only covers the top half, because each x can look up just one y.
  • Implicit is an inspector: give me a point and I tell you which side it is on. With f(x, y) = x² + y² − r², negative is inside, positive outside, and 0 exactly on the circle. But it never volunteers which points lie on the circle.
  • Parametric is the motion of a pen: as time t runs, the tip is at P(t) = (r cos 2πt, r sin 2πt). Take as many t values as you want points, but it cannot directly answer "is this point inside?".

图形学两大渲染方法正好对应后两种：光栅化要"造点"去填像素，用参数式；光线追踪要"判断打没打中"，常用隐式。

The two big rendering methods line up with the last two: rasterization needs to produce points to fill pixels (parametric); ray tracing needs to test whether a ray hits (often implicit).

Math数学Math

              圆（圆心 C，半径 r）/ circle            直线（过 A、B）/ line through A, B
显式 explicit   y = C_y ± √(r² − (x − Cₓ)²)          y = m x + b      （竖直线写不出 / no vertical lines）
隐式 implicit   f = (x − Cₓ)² + (y − C_y)² − r² = 0    f = n · (P − A) = 0,  n ⟂ (B − A)
参数 param.     P(t) = C + r (cos 2πt, sin 2πt)       P(t) = A + t (B − A)

隐式的正负：f < 0 在里面（或直线的一侧），f > 0 在外面（另一侧），f = 0 在曲线上。直线的 f = n · (P − A) 就是 1.2 课的点积，n 是法线；在 2D 里也可以写成 1.3 课叉积的 z 分量 ((B − A) × (P − A))_z，正数表示 P 在 A→B 的左边。

Sign of an implicit f: f < 0 is inside (or one side of a line), f > 0 outside (the other side), f = 0 on the curve. A line's f = n · (P − A) is lesson 1.2's dot product with normal n; in 2D it is also the z component of lesson 1.3's cross product ((B − A) × (P − A))_z, positive when P is left of A→B.

参数式的 t：直线 P(t) = A + t(B − A) 中，t = 0 在 A，t = 1 在 B，0 到 1 之间是线段，t > 1 或 t < 0 是延长线。圆的 P(t) 中 t 从 0 到 1 正好一圈；把 2πt 换成 2πkt + φ，k 控制圈数和方向（负数顺时针），φ 控制起点。

The t of a parametric curve: for the line P(t) = A + t(B − A), t = 0 is A, t = 1 is B, values between give the segment, and t > 1 or t < 0 extend it. For the circle, t from 0 to 1 is exactly one turn; replace 2πt with 2πkt + φ and k sets the number of turns and direction (negative is clockwise) while φ sets the start.

Why为什么三种写法说的是同一个圆？Why do the three forms describe the same circle?

1. 隐式 → 显式：解出 y

1. Implicit → explicit: solve for y

从 x² + y² = r² 解 y，得到 y = ±√(r² − x²)。开平方有正负两个根，所以显式必须拆成上下两个函数。这就是"一个 x 只能有一个 y"的代价：显式只能表示"竖直线最多穿过一次"的曲线。

Solving x² + y² = r² for y gives y = ±√(r² − x²). A square root has two signs, so the explicit form must split into top and bottom functions. That is the price of "one y per x": explicit form only covers curves that any vertical line crosses at most once.

2. 参数式 → 隐式：代进去验证

2. Parametric → implicit: substitute and check

把 x = r cos θ、y = r sin θ 代进 x² + y² − r²，得到 r²(cos²θ + sin²θ) − r² = 0，因为 cos²θ + sin²θ = 1。所以参数式造出来的每个点，都满足隐式方程。反过来，从参数式消去 t 就得到隐式。练习的第 4 条测试就是在检查这件事。

Substitute x = r cos θ, y = r sin θ into x² + y² − r² and you get r²(cos²θ + sin²θ) − r² = 0, because cos²θ + sin²θ = 1. So every point the parametric form produces satisfies the implicit equation; eliminating t from the parametric form gives the implicit one. Test 4 in the exercise checks exactly this.

3. 直线的隐式就是点积

3. A line's implicit form is a dot product

点 P 在直线上，等价于 P − A 和直线方向平行，也就是和法线 n 垂直：n · (P − A) = 0。展开成 aₓx + a_y y + c = 0，其中 (a, b) 就是法线。1.2 课"点积的符号把平面切成两半"，在这里就变成了"直线把平面切成两侧"。

P lies on the line exactly when P − A is parallel to the line, i.e. perpendicular to its normal n: n · (P − A) = 0. Expanded, that is a x + b y + c = 0 with (a, b) the normal. Lesson 1.2's "the sign of a dot product splits the plane in two" becomes "a line splits the plane into two sides".

4. 物理：抛体运动

4. Physics: a thrown ball

斜抛一个球，位置随时间是参数式：x = vₓ t，y = v_y t − ½ g t²。消去时间 t = x / vₓ，就得到显式 y = (v_y / vₓ) x − g x² / (2vₓ²)，一条抛物线。参数式多告诉你一件事：球在什么时候到哪里。显式只剩下形状，时间信息丢了。

Throw a ball and its position over time is parametric: x = vₓ t, y = v_y t − ½ g t². Eliminate time with t = x / vₓ and you get the explicit y = (v_y / vₓ) x − g x² / (2vₓ²), a parabola. The parametric form says one more thing, when the ball is where; the explicit form keeps only the shape and loses the timing.

      function circleF(c, r, P) { const d = P.sub(c); return d.dot(d) - r * r; }
function circlePoint(c, r, t) {
  const a = 2 * Math.PI * t;
  return c.add(new Vec3(Math.cos(a), Math.sin(a), 0).scale(r));
}
function linePoint(A, B, t) { return A.add(B.sub(A).scale(t)); }
function lineSide(A, B, P)  { return B.sub(A).cross(P.sub(A)).z; }
function sampleCircle(c, r, n) {
  const pts = [];
  for (let i = 0; i < n; i++) pts.push(circlePoint(c, r, i / n));   // i / n，不是 i / (n − 1)
  return pts;
}

      Pitfalls常见误区Common mistakes

      • 用显式画圆。y = √(r² − x²) 只有上半圆；而且越靠近左右两端，x 每走一步 y 变化越大，均匀取 x 画出来的点在两端会很稀疏。
      • sampleCircle 首尾重复。用 i / (n − 1) 取 t，最后一个点 t = 1 和第一个点 t = 0 是同一个位置，画闭合曲线时会多出一条零长度的边。
      • 以为隐式的 f 值就是距离。x² + y² − r² 的大小不是到圆的距离（它是"距离的平方差"）。只有特别构造的"有向距离场"（SDF）才等于距离，后面光线步进会用到。
      • 直线方程用 y = mx + b。竖直线斜率无穷大写不出来，接近竖直时数值也不稳定。图形学里几乎都用隐式 n · P + c = 0 或参数式。
      • Drawing a circle explicitly. y = √(r² − x²) is only the top half, and near the left and right ends y changes faster per step of x, so evenly spaced x values leave sparse points there.
      • sampleCircle repeating its first point. With t = i / (n − 1), the last point at t = 1 lands on the first at t = 0, adding a zero-length edge to a closed curve.
      • Treating the implicit f as a distance. x² + y² − r² is not the distance to the circle (it is a difference of squares). Only a specially built signed distance field (SDF) equals the distance; ray marching uses those later.
      • Writing lines as y = mx + b. Vertical lines have infinite slope and cannot be written, and nearly vertical ones are numerically unstable. Graphics almost always uses the implicit n · P + c = 0 or the parametric form.
