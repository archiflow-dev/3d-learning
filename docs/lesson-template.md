# 课程页模板规范

模板文件：[templates/lesson-template.html](../templates/lesson-template.html)（就是第 0.1 课的副本）。每节新课都从它复制，**不改结构，只填内容**。这样后面合并成网站时不需要重做任何页面。

**中英双语（2026-11-03 起）**：每段文字写两份，`class="zh"` 和 `class="en"`；页面右上角的按钮切换语言，选择存在浏览器里，第一次打开时跟随浏览器语言。JS 里显示的文字放进 `{zh, en}` 字典。两种语言内容必须对等，不能一边详细一边简略。

## 每节课的固定区块（顺序不变）

| 区块 | id | 内容 | 要求 |
|---|---|---|---|
| 页头 | `#meta` | 阶段、课号、标题、预计用时、前置课 | 由页面顶部的 `LESSON` 对象生成 |
| 学习目标 | `#goals` | 3 条以内，"学完后能做到……" | 必须可检验 |
| 直觉 | `#intuition` | 一段话 + 一张图，不用公式 | |
| 交互演示 | `#demo` | 核心 canvas / three.js 场景 | 页面的主角，必须能拖、能调 |
| 数学 | `#math` | 公式推导（KaTeX） | 每个公式旁边写清符号含义 |
| 你动手 | `#exercise` | 你自己写的代码任务 + 你的解答 | **这一块必须是你写的**，AI 只出题和评审 |
| 常见误区 | `#pitfalls` | 2–4 条 | |
| 自测 | `#quiz` | 3–5 道题，答案折叠 | |
| 参考资料 | `#refs` | 书的章节、GAMES101 对应集数、外部视频链接 | 视频用**链接 + 时间点**，不下载、不转载 |
| 导航 | `#nav` | 上一课 / 下一课 / 回目录、"标记完成" | |

## 硬规则

1. **单文件**：每课一个 `.html`，不写 `<!doctype>`/`<html>`/`<head>`/`<body>`（发布 artifact 时会自动包上；以后建网站时由构建脚本补上），CSS 和 JS 内联，外部库只从 jsdelivr 按固定版本加载。这样同一个文件既能直接发布成 Claude artifact，也能原样放到 GitHub Pages。
2. **固定版本**：three.js、KaTeX 版本写在模板里，全站统一，不要每课随手换版本。
3. **文件名 = 课号**：`lessons/1.2-dot-product.html`。课号一旦发布不再改，避免外链失效。
4. **元数据在页面顶部的 `LESSON` 对象里**，和 `lessons.json` 里的条目保持一致。
5. **光栅化和光追的核心课（阶段 3、5）不用 three.js**，用 Canvas 2D 或原生 WebGL 从零写。否则你学的是 three.js 的 API，不是原理。
6. **署名和免责**：页脚写明"学习笔记，由我与 AI 共同制作，可能有错误"，并附参考资料。

## 每节课的流程（和 AI 怎么配合）

1. **讲解与对话**（30–60 分钟）：AI 讲概念，你提问，AI 反问你检验理解。
2. **你先做练习**：在不看答案的情况下写 `#exercise` 的代码。
3. **AI 做页面**：AI 按模板生成交互页面，你检查演示是否和你理解的一致。
4. **AI 评审你的代码**，你改完后放进页面的 `#exercise`。
5. **更新 `lessons.json`**：状态改成 `done`，写完成日期。
6. **发布**（可选）：发布为 artifact，同时提交到 git 仓库。
