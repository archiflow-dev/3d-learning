Goals学习目标Learning goals

  • 顺序会改变结果，而且有两种读法：M = A · B 表示先做 B、再做 A（从右往左读，物体在固定的世界坐标里移动）。同一个式子也可以从左往右读：先把坐标系做 A，再在新坐标系里做 B。两种读法结果一样。
  • 物体矩阵用 T · R · S：先缩放、再旋转、最后平移。这样缩放沿物体自己的轴，旋转绕物体自己的中心，第三列正好是物体的位置。顺序一乱，就会出现「公转」或剪切。
  • 法线要用 (M⁻¹)ᵀ 变换：法线必须和表面保持垂直。旋转、均匀缩放时直接用 M 没问题；不均匀缩放或剪切时，要用左上 3×3 的逆的转置，再归一化。
  • Order changes the result, and there are two ways to read it: M = A · B means do B first, then A (read right to left: the object moves in a fixed world frame). The same product can be read left to right: first apply A to the coordinate frame, then do B in the new frame. Both readings give the same result.
  • Object matrices are T · R · S: scale first, then rotate, then translate. Scaling then follows the object's own axes, rotation turns about the object's own center, and column 3 is exactly the object's position. Mix up the order and you get an "orbit" or a shear.
  • Normals transform by (M⁻¹)ᵀ: a normal must stay perpendicular to its surface. Rotations and uniform scales can use M directly; non-uniform scales and shears need the inverse transpose of the top-left 3×3, followed by normalizing.

Intuition直觉Intuition

穿袜子再穿鞋，和穿鞋再穿袜子，结果完全不同。变换也一样：「先转 90° 再右移 3」是原地转身后走开；「先右移 3 再转 90°」是走开后绕着原点公转了四分之一圈。

Socks then shoes is not the same as shoes then socks. Transforms are the same: "turn 90°, then move right 3" spins in place and walks off; "move right 3, then turn 90°" walks off and then swings a quarter orbit around the origin.

游戏引擎给每个物体存三样东西：位置、旋转、缩放。它们总是按 T · R · S 拼起来：先在物体自己的原点把它缩放、转好，最后整个搬到位置上。你在 three.js 里改 rotation，物体总是「原地转」，原因就是这个顺序。

A game engine stores three things per object: position, rotation and scale. They are always combined as T · R · S: scale and turn the object around its own origin, then carry the whole thing to its position. That order is why changing rotation in three.js always spins the object in place.

法线是个特例。把一个圆压扁成椭圆，表面上的切线跟着被压扁；可法线如果也跟着被压扁，就不再垂直于表面了。法线要「反着」变：表面在 x 方向拉长 2 倍，法线的 x 分量反而要缩小一半。

Normals are the special case. Squash a circle into an ellipse and the tangents along its edge get squashed too; if the normals were squashed the same way they would no longer be perpendicular to the surface. Normals must change the opposite way: stretch the surface ×2 along x and the normal's x-component must shrink by half.

The last formula reuses the cross product from lesson 1.3 and det from lesson 1.5: b × c is perpendicular to both b and c, so a · (b × c) = det while b · (b × c) = c · (b × c) = 0. That is exactly what "inverse times matrix = identity" requires.

Why为什么法线要用逆转置？Why do normals need the inverse transpose?

1. 几何：把圆压扁，看法线（拖动滑块）

1. Geometry: squash a circle and watch the normals (move the sliders)

单位圆上每一点的法线就是这个点本身的方向。用 M 把圆变成椭圆，再用两种办法变换法线：玫红色直接用 M，绿色用 (M⁻¹)ᵀ。灰色短线是该点的切线（表面方向）。拉大 sx 或加一点剪切，玫红色很快就不垂直了，绿色始终垂直。

On the unit circle, the normal at each point is the point's own direction. Turn the circle into an ellipse with M and transform the normals two ways: magenta uses M directly, green uses (M⁻¹)ᵀ. The short gray lines are the tangents (the surface direction). Increase sx or add some shear and the magenta normals quickly stop being perpendicular, while the green ones always are.

2. 代数：垂直这件事必须保住

2. Algebra: perpendicularity must survive

切线 t 在表面上，法线 n 垂直于它：nᵀ t = 0。变换后切线变成 A t（它就是表面上两点之差，按方向变换）。我们要找一个矩阵 N，让 (N n)ᵀ (A t) = 0 对所有 t 成立。展开：nᵀ Nᵀ A t = 0。只要 Nᵀ A = I，就变回原来的 nᵀ t = 0，所以 Nᵀ = A⁻¹，N = (A⁻¹)ᵀ。

A tangent t lies in the surface and the normal n is perpendicular to it: nᵀ t = 0. After the transform the tangent becomes A t (it is a difference of two surface points, transformed as a direction). We want a matrix N with (N n)ᵀ (A t) = 0 for every t. Expand: nᵀ Nᵀ A t = 0. If Nᵀ A = I this is the original nᵀ t = 0, so Nᵀ = A⁻¹ and N = (A⁻¹)ᵀ.

什么时候 N 就等于 A？旋转 R 满足 R⁻¹ = Rᵀ，所以 (R⁻¹)ᵀ = R。均匀缩放 k·I 的逆转置是 (1/k)·I，只差一个倍数，归一化后方向一样。所以只有旋转加均匀缩放时，「直接用 M」才碰巧没错。对 A = R · S，(A⁻¹)ᵀ = (S⁻¹ R⁻¹)ᵀ = (R⁻¹)ᵀ (S⁻¹)ᵀ = R · S⁻¹：旋转照旧，缩放取倒数。

When is N just A? A rotation satisfies R⁻¹ = Rᵀ, so (R⁻¹)ᵀ = R. A uniform scale k·I has inverse transpose (1/k)·I, which differs only by a factor, so the direction is the same after normalizing. That is why "just use M" happens to work only for rotations plus uniform scales. For A = R · S, (A⁻¹)ᵀ = (S⁻¹ R⁻¹)ᵀ = (R⁻¹)ᵀ (S⁻¹)ᵀ = R · S⁻¹: same rotation, reciprocal scale.

3. 物理：法线是「每米变化多少」

3. Physics: a normal measures "change per meter"

表面可以看成一个函数 f(x, y) = 0 的等值线，法线就是 f 的梯度 ∇f，也就是「往哪个方向走，f 变得最快，每米变多少」。想象一张温度地图：每隔 1 米温度升高 1 度。把地图在 x 方向拉长 2 倍，同样的温差现在分布在 2 米上，梯度的 x 分量就变成每米 0.5 度。

A surface can be seen as the level set f(x, y) = 0 of a function, and its normal is the gradient ∇f: the direction in which f grows fastest, and by how much per meter. Picture a temperature map that rises 1 degree per meter. Stretch the map ×2 along x and the same temperature difference is now spread over 2 meters, so the gradient's x-component becomes 0.5 degree per meter.

普通方向（速度、切线）的单位是「米」，拉长空间它就跟着变长；法线的单位是「每米」，拉长空间它反而变短。所以一个乘 S，一个乘 S⁻¹。物理里这两类量分别叫向量和余向量（covector）。

An ordinary direction (a velocity, a tangent) is measured in meters, so stretching space makes it longer; a normal is measured in "per meter", so stretching space makes it shorter. One gets multiplied by S, the other by S⁻¹. Physics calls these two kinds of quantities vectors and covectors.

Deep dive深入：逆、转置和逆转置Deep dive: inverse, transpose and inverse transpose

这一节把「(M⁻¹)ᵀ 到底是什么」拆开讲：平面方程、转置、求逆，最后讲它的几何意义和物理意义。每一部分都有可以播放的动画。

This section takes "what exactly is (M⁻¹)ᵀ" apart: the plane equation, the transpose, the inverse, and finally its geometric and physical meaning. Each part has an animation you can play.

1. 平面方程 n · x = d

1. The plane equation n · x = d

在平面上取一个固定点 p₀。对平面上任意一点 x，向量 x − p₀ 躺在平面里，所以和法线 n 垂直：n · (x − p₀) = 0，也就是 n · x = n · p₀。右边是一个固定的数，记作 d。平面就是所有满足 n · x = d 的点。

Fix a point p₀ on the plane. For any point x on the plane, x − p₀ lies in the plane and is therefore perpendicular to the normal n: n · (x − p₀) = 0, i.e. n · x = n · p₀. The right side is a fixed number, call it d. The plane is every point satisfying n · x = d.

n 是单位向量时，n · x 是 x 在 n 方向上的投影长度（1.2 课），所以平面就是「沿法线看高度都是 d 的那一层」，|d| 是原点到平面的距离。例子：地面 n = (0, 1, 0)、d = 0，展开就是 y = 0；n = (1, 1, 0)、d = 2 展开是 x + y = 2，一个竖直的斜面。1.4 课的 lineSide 就是 2D 版的 n · x − d：等于 0 在线上，正负号表示在哪一侧。弯曲的表面在一点附近放大看几乎是平面（切平面），法线说的就是这个切平面的 n。

When n is a unit vector, n · x is the length of x's projection onto n (lesson 1.2), so the plane is "the layer whose height along the normal is d", and |d| is the distance from the origin. Examples: the ground n = (0, 1, 0), d = 0 expands to y = 0; n = (1, 1, 0), d = 2 expands to x + y = 2, a vertical slanted wall. Lesson 1.4's lineSide is the 2D n · x − d: zero on the line, its sign tells the side. A curved surface looks almost flat near any point when you zoom in (the tangent plane), and its normal is that tangent plane's n.

2. 转置：行变成列（动画）

2. Transpose: rows become columns (animation)

转置 Aᵀ 就是沿主对角线（左上到右下）把矩阵翻过来：第 r 行第 c 列的数搬到第 c 行第 r 列。对角线上的数不动。播放动画，看三种颜色的行怎么变成三种颜色的列。

The transpose Aᵀ flips the matrix across its main diagonal (top-left to bottom-right): the entry in row r, column c moves to row c, column r. Diagonal entries stay put. Play the animation and watch the three colored rows become three colored columns.

为什么转置能让矩阵「跨过点积」：u · (A v) = (Aᵀ u) · v

Why the transpose lets a matrix "hop across" a dot product: u · (A v) = (Aᵀ u) · v

代数：点积就是一行乘一列：u · v = uᵀ v。所以 u · (A v) = uᵀ (A v) = (uᵀ A) v。uᵀ A 是一行，把它竖起来就是 Aᵀ u，于是等于 (Aᵀ u) · v。只用了「矩阵乘法可以换括号」，转置负责把行和列对调。2D 展开验证：u₁(a v₁ + b v₂) + u₂(c v₁ + d v₂) = v₁(a u₁ + c u₂) + v₂(b u₁ + d u₂)，括号里正是 Aᵀ u。

Algebra: a dot product is a row times a column: u · v = uᵀ v. So u · (A v) = uᵀ (A v) = (uᵀ A) v. uᵀ A is a row; stand it up and it is Aᵀ u, so this equals (Aᵀ u) · v. All it uses is that matrix products can be regrouped, with the transpose swapping rows and columns. Check in 2D: u₁(a v₁ + b v₂) + u₂(c v₁ + d v₂) = v₁(a u₁ + c u₂) + v₂(b u₁ + d u₂), and the brackets are exactly Aᵀ u.

几何：左边是「先用 A 变换 v，再用尺子 u 量它」；右边是「不变换 v，换一把尺子 Aᵀ u 直接量」。两边量出来是同一个数。下面拖动左图里的 v 试试。

Geometry: the left side is "transform v by A, then measure it with the ruler u"; the right side is "leave v alone and measure it with a different ruler, Aᵀ u". Both give the same number. Drag v in the left picture below.

3. 求逆：把变换撤销（动画）

3. The inverse: undoing a transform (animation)

M⁻¹ 满足 M · M⁻¹ = I：做了 M 再做 M⁻¹，等于什么都没做。图形学里求逆有几种做法，按常用程度排：

M⁻¹ satisfies M · M⁻¹ = I: doing M and then M⁻¹ is doing nothing. Graphics uses several ways to compute it, roughly in order of how often:

  • 知道是什么变换，就反着做：T(t)⁻¹ = T(−t)，R(θ)⁻¹ = R(−θ) = Rᵀ，S⁻¹ = S(1/sx, 1/sy, 1/sz)，(A · B)⁻¹ = B⁻¹ · A⁻¹。所以 (T · R · S)⁻¹ = S⁻¹ · R⁻¹ · T⁻¹，相机的视图矩阵就是这样求的。
  • 仿射 Mat4 分两块：M = [[A, t], [0, 1]]。y = A x + t 倒过来是 x = A⁻¹ y − A⁻¹ t，所以 M⁻¹ = [[A⁻¹, −A⁻¹ t], [0, 1]]，只需要求一个 3×3 的逆。
  • 2×2 公式：主对角线互换，副对角线变号，再除以 det（下面有动画）。
  • 3×3 用叉积：A 的三列是 a、b、c，det = a · (b × c)，A⁻¹ 的三行是 (b × c)/det、(c × a)/det、(a × b)/det。因为 b × c 和 a 点乘得 det，和 b、c 点乘得 0。把这三个当成列，就直接得到逆转置（练习里的 normalMatrix）。
  • 通用：高斯-约当消元。把 [A | I] 并排写，用行操作把左边变成 I，右边就成了 A⁻¹（下面有逐步动画）。
  • det = 0 没有逆：空间被压扁了，信息丢了，撤销不了。代码里要先检查 det 是否接近 0。
  • If you know the transform, run it backwards: T(t)⁻¹ = T(−t), R(θ)⁻¹ = R(−θ) = Rᵀ, S⁻¹ = S(1/sx, 1/sy, 1/sz), (A · B)⁻¹ = B⁻¹ · A⁻¹. So (T · R · S)⁻¹ = S⁻¹ · R⁻¹ · T⁻¹, which is how a camera's view matrix is computed.
  • Split an affine Mat4 in two: M = [[A, t], [0, 1]]. Reversing y = A x + t gives x = A⁻¹ y − A⁻¹ t, so M⁻¹ = [[A⁻¹, −A⁻¹ t], [0, 1]]; only a 3×3 inverse is needed.
  • The 2×2 formula: swap the main diagonal, negate the other diagonal, divide by det (animated below).
  • 3×3 with cross products: with columns a, b, c and det = a · (b × c), the rows of A⁻¹ are (b × c)/det, (c × a)/det, (a × b)/det, because b × c dotted with a gives det and with b or c gives 0. Use those three as columns and you get the inverse transpose directly (the exercise's normalMatrix).
  • General: Gauss–Jordan elimination. Write [A | I] side by side and use row operations to turn the left half into I; the right half becomes A⁻¹ (step-by-step animation below).
  • det = 0 has no inverse: space was flattened, information was lost, and nothing can undo it. Check whether det is near 0 in code.

撤销：F 先被 A 变换，再被 A⁻¹ 送回原处。Undo: F is transformed by A, then A⁻¹ sends it back.

高斯-约当消元：一步一步求逆

Gauss–Jordan elimination: the inverse step by step

三种行操作：交换两行、某行乘一个数、某行加上另一行的倍数。每一步都等于在左边乘一个「初等矩阵」，所以左右两边一起变；左边变成 I 时，右边累积的就是 A⁻¹。

固定套路：一列一列地处理。对第 j 列：① 如果对角线上的数（叫「主元」）是 0，先和下面某一行对调；② 把第 j 行整行除以主元，让主元变成 1；③ 对其他每一行，减去「这一行在第 j 列的数」倍的第 j 行，把这一列的其他位置都消成 0。处理完所有列，左边就是 I。下面每一步都会写出为什么这样做，以及每个数是怎么算出来的。

Three row operations: swap two rows, multiply a row by a number, add a multiple of one row to another. Each step equals multiplying on the left by an "elementary matrix", so both halves change together; when the left becomes I, the right has accumulated A⁻¹.

The fixed recipe: handle one column at a time. For column j: ① if the diagonal entry (the "pivot") is 0, swap with a row below; ② divide row j by the pivot so the pivot becomes 1; ③ for every other row, subtract (that row's entry in column j) times row j, clearing the rest of the column to 0. After all columns the left is I. Each step below says why it is done and how every number is computed.

三种行操作对应的矩阵（初等矩阵）

The matrices behind the three row operations (elementary matrices)

规律：对单位矩阵 I 做同样的行操作，得到的就是 E；左乘 E 就等于做这个行操作。因为 (E A) 的第 i 行 = 用 E 的第 i 行当权重，把 A 的各行加起来。以 3×3 为例：交换第 1、2 行，E = [[0, 1, 0], [1, 0, 0], [0, 0, 1]]，逆是它自己；第 2 行乘 k，E = diag(1, k, 1)，逆是 diag(1, 1/k, 1)（所以 k ≠ 0）；第 3 行减 f 倍第 1 行，E 是在 I 的第 3 行第 1 列放 −f，逆是放 +f。

Rule: do the same row operation to the identity I and you get E; left-multiplying by E performs that row operation. Row i of (E A) is the rows of A weighted by row i of E. For 3×3: swapping rows 1 and 2 is E = [[0, 1, 0], [1, 0, 0], [0, 0, 1]], its own inverse; multiplying row 2 by k is E = diag(1, k, 1) with inverse diag(1, 1/k, 1) (so k ≠ 0); subtracting f times row 1 from row 3 puts −f in row 3, column 1 of I, and its inverse puts +f there.

为什么偏偏是这三种：① 都能撤销，不丢信息（乘 0 会抹掉一行，撤销不了，所以不允许）；② 够用，任何可逆矩阵都能靠它们变成 I；③ 不改变方程组 A x = b 的解：交换方程顺序、方程两边同乘一个数、一个方程减去另一个的倍数，就是中学的消元法。为什么右边变成 A⁻¹：E_k ⋯ E₁ A = I，所以 E_k ⋯ E₁ = A⁻¹，右边从 I 出发经历同样的操作，正好等于这个乘积。

Why exactly these three: ① each can be undone, so nothing is lost (multiplying by 0 would wipe a row irreversibly, so it is not allowed); ② they suffice: any invertible matrix can be brought to I with them; ③ they do not change the solutions of A x = b: reordering equations, scaling both sides of one, and subtracting a multiple of one from another is school elimination. Why the right half becomes A⁻¹: E_k ⋯ E₁ A = I, so E_k ⋯ E₁ = A⁻¹, and the right half started as I and went through the same operations, so it equals that product.

惊喜：它们的几何意义。在 2D 里，交换两行 = 沿 y = x 镜像（det = −1），某行乘 k = 沿一个轴拉伸（det = k），减去另一行的倍数 = 剪切（det = 1）。所以高斯-约当顺便证明了：任何可逆矩阵都能拆成剪切、拉伸和镜像的乘积。它还能算 det：每次交换 det 乘 −1，每次乘 k 让 det 乘 k，剪切不变，最后是 det(I) = 1，倒推回去就是 det(A)。例如 [[2, 1], [1, 1]] 消元时乘过 1/2 和 2、没有交换，所以 det(A) = 1 ÷ (1/2 × 2) = 1，和 ad − bc 一致。

A surprise: their geometry. In 2D, swapping rows is the mirror across y = x (det = −1), scaling a row stretches one axis (det = k), and subtracting a multiple of a row is a shear (det = 1). So Gauss–Jordan quietly proves that every invertible matrix is a product of shears, stretches and mirrors. It also computes det: each swap multiplies det by −1, each scaling by k multiplies it by k, shears leave it alone, and the end is det(I) = 1; work backwards to get det(A). For [[2, 1], [1, 1]] the elimination scaled by 1/2 and 2 with no swaps, so det(A) = 1 ÷ (1/2 × 2) = 1, matching ad − bc.

4. 合起来：(M⁻¹)ᵀ 到底表示什么

4. Putting it together: what (M⁻¹)ᵀ really means

推导：点被变换成 x′ = M x，所以旧点 x = M⁻¹ x′。代回平面方程：n · (M⁻¹ x′) = d，用第 2 部分的恒等式把 M⁻¹ 跨到左边：((M⁻¹)ᵀ n) · x′ = d。逆是因为要从新点倒推旧点；转置是因为要把矩阵跨过点积，作用到 n 上。所以新法线 n′ = (M⁻¹)ᵀ n，而且 d 不变。顺便：(M⁻¹)ᵀ = (Mᵀ)⁻¹，先转置后求逆也一样。

Derivation: points become x′ = M x, so the old point is x = M⁻¹ x′. Substitute into the plane equation: n · (M⁻¹ x′) = d, and use the identity from part 2 to hop M⁻¹ to the left: ((M⁻¹)ᵀ n) · x′ = d. The inverse is there because we go back from new points to old ones; the transpose because the matrix hops across the dot product onto n. So the new normal is n′ = (M⁻¹)ᵀ n, and d is unchanged. Also: (M⁻¹)ᵀ = (Mᵀ)⁻¹; transposing first gives the same thing.

几何意义：法线代表一叠平行平面。n 可以看成 n · x = 0、1、2、3……这一叠平面，n 越长排得越密，|n| 就是「每走一米穿过几层」。把空间沿 x 拉长，这叠平面被拉开，每米穿过的层数变少，法线反而变短，方向偏向被压缩的那一侧。下面拖动滑块看：绿色 (M⁻¹)ᵀ n 的长度始终等于新的层密度，玫红 M · n 既不垂直，长度也不对。

Geometric meaning: a normal stands for a stack of parallel planes. Think of n as the stack n · x = 0, 1, 2, 3…; the longer n, the denser the stack, and |n| is "layers crossed per meter". Stretch space along x and the stack spreads apart, fewer layers are crossed per meter, and the normal gets shorter, tilting toward the squeezed side. Drag the sliders below: the green (M⁻¹)ᵀ n always has the length of the new layer density, while magenta M · n is neither perpendicular nor the right length.

有向面积：三角形两条边 a、b，a × b 的方向是法线、长度是面积的 2 倍。变换后有精确关系 (M a) × (M b) = det(M) · (M⁻¹)ᵀ (a × b)：一小块表面的法线和面积正好按 det · 逆转置变化。det < 0（镜像）时朝向翻转，就是从这里来的。

Oriented area: for triangle edges a and b, a × b points along the normal with length twice the area. After a transform, exactly (M a) × (M b) = det(M) · (M⁻¹)ᵀ (a × b): a surface patch's normal and area change by det times the inverse transpose. That is where the flipped orientation for det < 0 (a mirror) comes from.

物理意义：单位带「每米」的量都按逆转置变。梯度（温度每米升几度、电场 V/m、压强梯度）；波矢（每米几道波峰：介质拉长，波峰变疏，波矢变短）；晶体的倒格子（基矢满足 bᵢ · aⱼ = 2π δᵢⱼ，倒格子矩阵就是 2π (A⁻¹)ᵀ，X 射线衍射测到的正是它）。位移、速度、切线的单位是「米」，乘 M；法线、梯度、波矢的单位是「每米」，乘 (M⁻¹)ᵀ；两者的点积（米 × 每米）是没有单位的「穿过几层」，所以变换前后不变，这正是第 2 部分的恒等式。

Physical meaning: anything measured "per meter" transforms by the inverse transpose. Gradients (degrees per meter, electric field in V/m, pressure gradients); wave vectors (crests per meter: stretch the medium and the crests spread, so the wave vector shrinks); a crystal's reciprocal lattice (its basis satisfies bᵢ · aⱼ = 2π δᵢⱼ, so the reciprocal lattice matrix is 2π (A⁻¹)ᵀ, which is exactly what X-ray diffraction measures). Displacements, velocities and tangents are in meters and get M; normals, gradients and wave vectors are per meter and get (M⁻¹)ᵀ; their dot product (meters × per meter) is a unitless "layers crossed" and survives the transform, which is precisely the identity from part 2.

手算例子（剪切 M = [[1, 1], [0, 1]]）：M⁻¹ = [[1, −1], [0, 1]]，(M⁻¹)ᵀ = [[1, 0], [−1, 1]]。水平线 y = 1、n = (0, 1)：剪切只把 x 加上 y，水平线还是水平，逆转置给出 (0, 1)，对；M · n = (1, 1) 斜了 45°，错。竖线 x = 0、n = (1, 0)：点 (0, y) 变成 (y, y)，线变成方向 (1, 1) 的斜线；逆转置给出 (1, −1)，和 (1, 1) 点积为 0，对；M · n = (1, 0)，点积为 1，错。

Worked example (shear M = [[1, 1], [0, 1]]): M⁻¹ = [[1, −1], [0, 1]], (M⁻¹)ᵀ = [[1, 0], [−1, 1]]. The horizontal line y = 1 with n = (0, 1): the shear only adds y to x, so the line stays horizontal; the inverse transpose gives (0, 1), right; M · n = (1, 1) tilts 45°, wrong. The vertical line x = 0 with n = (1, 0): the point (0, y) goes to (y, y), so the line becomes the diagonal with direction (1, 1); the inverse transpose gives (1, −1), whose dot with (1, 1) is 0, right; M · n = (1, 0) has dot 1, wrong.

在代码里怎么用：每个物体算一次法线矩阵（左上 3×3 的逆转置，不含平移），每个顶点算 n′ = normalize(N n)；片元着色器里插值后的法线还要再归一化一次。three.js 用 new Matrix3().getNormalMatrix(object.matrixWorld)，着色器内置的 normalMatrix 是 modelViewMatrix 左上 3×3 的逆转置。反正要归一化，也可以不除以 det，直接用 (b × c, c × a, a × b) 当列（余子式矩阵），镜像时它还能让法线跟着三角形一起翻面。

Using it in code: compute the normal matrix once per object (inverse transpose of the top-left 3×3, no translation) and n′ = normalize(N n) per vertex; normalize again in the fragment shader after interpolation. three.js uses new Matrix3().getNormalMatrix(object.matrixWorld), and the shader's built-in normalMatrix is the inverse transpose of modelViewMatrix's top-left 3×3. Since you normalize anyway, you can skip dividing by det and use (b × c, c × a, a × b) as columns (the cofactor matrix), which also flips the normal along with the triangle under a mirror.

static compose(t, theta, s) {      // 最右边的 S 最先做 / the rightmost S happens first
  return Mat4.translation(t.x, t.y, t.z).mul(Mat4.rotationZ(theta)).mul(Mat4.scaling(s.x, s.y, s.z));

normalMatrix() {
  const m = this.m;
  const a = new Vec3(m[0], m[4], m[8]), b = new Vec3(m[1], m[5], m[9]), c = new Vec3(m[2], m[6], m[10]);
  const det = a.dot(b.cross(c));
  const p = b.cross(c).scale(1 / det), q = c.cross(a).scale(1 / det), r = a.cross(b).scale(1 / det);
  return new Mat4([p.x, q.x, r.x, 0,  p.y, q.y, r.y, 0,  p.z, q.z, r.z, 0,  0, 0, 0, 1]);   // p, q, r 是列 / are columns
}
transformNormal(n) { return this.normalMatrix().transformDirection(n).normalize(); }

      Pitfalls常见误区Common mistakes

      • 按执行顺序从左往右写。「先缩放、再旋转、再平移」写成矩阵是 T · R · S，不是 S · R · T。写的顺序和执行顺序相反。
      • 先旋转再做不均匀缩放。S · R（先转后缩放）会让直角变斜，也就是剪切。这样的矩阵拆不回位置、旋转、缩放三样，three.js 的 decompose 也会给出错的结果。
      • 法线直接乘模型矩阵。只有旋转和均匀缩放时碰巧对。three.js 用 Matrix3.getNormalMatrix(matrix4) 计算逆转置，着色器里的 normalMatrix 也是这样来的。
      • 法线变换后忘了归一化。逆转置会改变长度，光照公式需要单位法线（1.2 课的点积）。
      • 把平移也放进法线矩阵。法线是方向，w = 0，只用左上 3×3。
      • Writing the steps left to right in execution order. "Scale, then rotate, then translate" is the matrix T · R · S, not S · R · T. Written order is the reverse of execution order.
      • Rotating before a non-uniform scale. S · R (rotate, then scale) bends right angles, which is a shear. Such a matrix cannot be split back into position, rotation and scale, and three.js's decompose gives wrong results for it.
      • Multiplying normals by the model matrix. It only happens to work for rotations and uniform scales. three.js computes the inverse transpose with Matrix3.getNormalMatrix(matrix4), which is also where the shader's normalMatrix comes from.
      • Forgetting to normalize the transformed normal. The inverse transpose changes length, and lighting needs unit normals (the dot product from lesson 1.2).
      • Putting the translation into the normal matrix. A normal is a direction with w = 0; use only the top-left 3×3.

      M⁻¹ = S⁻¹ · R⁻¹ · T⁻¹ = S(1/sx, 1/sy, 1/sz) · R(−θ) · T(−t). Undo in reverse: undo the last step (translation) first, then the rotation, then the scale.
