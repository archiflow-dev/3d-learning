Goals学习目标Learning goals

  • 矩阵的列 = 基向量去了哪里：看一张变形后的图能写出矩阵，看一个矩阵能想象出变形；知道 M v = x · (第 1 列) + y · (第 2 列)。
  • 行列式 = 面积（体积）的放大倍数：det > 1 放大、0 到 1 缩小、= 0 压扁成一条线、< 0 翻面（镜像）。知道 2×2 的 det 就是 1.3 课叉积的 z 分量。
  • 矩阵乘法 = 依次做两个变换，顺序不能换：A B v 是先做 B、再做 A（从右往左读）；一般 A B ≠ B A。
  • A matrix's columns are where the basis vectors land: read a matrix off a deformed picture and picture the deformation from a matrix; know that M v = x · (column 1) + y · (column 2).
  • The determinant is the area (volume) scale factor: det > 1 grows, between 0 and 1 shrinks, = 0 squashes onto a line, < 0 flips (mirrors). A 2×2 det is the z component of lesson 1.3's cross product.
  • Matrix multiplication means doing two transforms in turn, and order matters: A B v does B first, then A (read right to left); in general A B ≠ B A.

Intuition直觉Intuition

把平面想象成一张画着方格的橡皮膜。线性变换就是拉、转、斜推这张膜，但有两条规矩：原点不动，网格线变形后仍然是直的、平行的、等间距的。

Think of the plane as a rubber sheet with a grid drawn on it. A linear transformation stretches, turns or shears the sheet under two rules: the origin stays put, and grid lines stay straight, parallel and evenly spaced.

因为网格是均匀的，只要知道两个基向量 î = (1, 0) 和 ĵ = (0, 1) 被送到了哪里，整张膜上每个点去哪就全确定了。点 (3, 2) 原来是「向 î 走 3 步、向 ĵ 走 2 步」，变形后还是「向新 î 走 3 步、向新 ĵ 走 2 步」。把新 î、新 ĵ 竖着写成两列，就是矩阵。

Because the grid stays even, knowing where the two basis vectors î = (1, 0) and ĵ = (0, 1) land pins down where every point goes. The point (3, 2) was "3 steps along î, 2 along ĵ"; after the change it is "3 steps along the new î, 2 along the new ĵ". Write the new î and new ĵ as two columns and you have the matrix.

矩阵乘法：(A B) v = A (B v)，先做 B 再做 A。A B 的第 1 列是 A 作用在 B 的第 1 列上：「B 把 î 送到哪，A 再把它送到哪」。3D 的 Mat3 完全一样，只是多了第 3 列 k̂，det 变成体积倍数，等于三列的混合积 a · (b × c)。

Matrix multiplication: (A B) v = A (B v): B first, then A. The first column of A B is A applied to B's first column: "where B sends î, then where A sends that". A 3D Mat3 works the same way with a third column k̂; the det becomes the volume factor and equals the triple product a · (b × c) of the three columns.

Why为什么 M v = x · 第 1 列 + y · 第 2 列？为什么 det = ad − bc？Why is M v = x · column 1 + y · column 2? Why is det = ad − bc?

1. 几何：网格均匀，所以只看基向量

1. Geometry: an even grid means only the basis matters

v = x î + y ĵ。线性变换 T 保持「加法」和「数乘」：T(x î + y ĵ) = x T(î) + y T(ĵ)。所以 T(v) 只取决于 T(î) 和 T(ĵ) 这两个向量。把它们当成两列，「矩阵乘向量」就是按 x、y 把两列加权相加。在演示里拖动 x、y 滑块，虚线就是先走 x 个新 î、再走 y 个新 ĵ。

v = x î + y ĵ. A linear map T keeps addition and scaling: T(x î + y ĵ) = x T(î) + y T(ĵ). So T(v) depends only on the two vectors T(î) and T(ĵ). Make them the two columns, and "matrix times vector" is just the columns weighted by x and y. Move the x and y sliders in the demo: the dashed path walks x new î's, then y new ĵ's.

2. 代数：「行乘列」和「列的组合」是同一件事

2. Algebra: row-times-column and column combination are the same thing

课本常写 (M v)ₓ = a x + b y，即第 1 行和 v 做点积（1.2 课）。把两行的结果竖着放：(a x + b y, c x + d y) = x (a, c) + y (b, d)。左边是「按行算」，右边是「按列看」。算的时候按行，理解的时候按列。

Textbooks often write (M v)ₓ = a x + b y, the dot product of row 1 with v (lesson 1.2). Stack both rows: (a x + b y, c x + d y) = x (a, c) + y (b, d). The left is the row view, the right the column view. Compute by rows, understand by columns.

3. 行列式：单位正方形变成了什么

3. Determinant: what the unit square becomes

单位正方形由 î、ĵ 张成，面积是 1。变换后它变成由两列 (a, c)、(b, d) 张成的平行四边形。1.3 课讲过，平行四边形面积就是叉积的长度：(a, c, 0) × (b, d, 0) = (0, 0, a d − b c)。因为网格均匀，每个小方格都放大同样的倍数，所以任何图形的面积都乘以 a d − b c。符号就是叉积的方向：正的说明 î 到 ĵ 仍然是逆时针，负的说明顺序反了，平面被翻了个面。

The unit square is spanned by î and ĵ, with area 1. Afterwards it is the parallelogram spanned by the columns (a, c) and (b, d). Lesson 1.3 showed that a parallelogram's area is a cross product's length: (a, c, 0) × (b, d, 0) = (0, 0, a d − b c). Because the grid stays even, every little square grows by the same factor, so every shape's area is multiplied by a d − b c. The sign is the cross product's direction: positive means î to ĵ is still counter-clockwise, negative means the order reversed and the plane was flipped over.

4. 物理：橡皮膜的形变

4. Physics: deforming a rubber sheet

连续介质力学里，材料局部的形变就用一个矩阵（形变梯度 F）描述，det F 是体积变化比例：1 表示不可压缩（橡胶近似如此），小于 1 是被压缩。det F 永远不会是负数，因为真实材料不可能「穿过自己」翻面。动画和物理模拟（阶段 7）里，检测到 det < 0 往往就说明网格被挤翻、算崩了。

In continuum mechanics a material's local deformation is a matrix (the deformation gradient F), and det F is the volume ratio: 1 means incompressible (rubber is close), under 1 means compressed. det F is never negative, because real material cannot pass through itself and turn inside out. In animation and physics simulation (stage 7), a det < 0 usually means an element got inverted and the simulation broke.

    • mulVec(v)：返回 M v（一个 Vec3）。

    • det()：行列式。
    • Mat3.rotationZ(theta)：绕 z 轴逆时针旋转 theta 弧度（在 xy 平面里转）。

    • mulVec(v): returns M v (a Vec3).
    • mul(B): returns this × B, i.e. "B first, then this".
    • det(): the determinant.
    • Mat3.rotationZ(theta): rotate counter-clockwise by theta radians about the z axis (turning the xy plane).

      我的解答（2026-11-07，8/8 通过）My solution (2026-11-07, 8/8 pass)

      static fromColumns(a, b, c) { return new Mat3([a.x, b.x, c.x,  a.y, b.y, c.y,  a.z, b.z, c.z]); }
mulVec(v)  { const m = this.m;
  return new Vec3(m[0] * v.x + m[1] * v.y + m[2] * v.z,
                  m[3] * v.x + m[4] * v.y + m[5] * v.z,
                  m[6] * v.x + m[7] * v.y + m[8] * v.z); }
mul(B)     { const r = [];
  for (let i = 0; i < 3; i++) for (let j = 0; j < 3; j++)
    r.push(this.get(i, 0) * B.get(0, j) + this.get(i, 1) * B.get(1, j) + this.get(i, 2) * B.get(2, j));
  return new Mat3(r); }
det()      { const col = j => new Vec3(this.get(0, j), this.get(1, j), this.get(2, j));
  return col(0).dot(col(1).cross(col(2))); }
static rotationZ(t) { const c = Math.cos(t), s = Math.sin(t);
  return new Mat3([c, -s, 0,  s, c, 0,  0, 0, 1]); }

      评审时学到的：（代码和参考答案相同，所以主要靠理解题判断。）fromColumns 把三列竖着放；如果按行存，mulVec((1,0,0)) 会返回第 1 行 (a.x, b.x, c.x)，整个矩阵变成转置，旋转方向也会反。det = a · (b × c)：|b × c| 是底面积，方向是底面的法线（不是「角度」，我一开始答错了），a 点乘单位法线是高，所以是底面积 × 高 = 体积，符号表示三列是不是右手系。R·H 表示先剪切 H 再旋转 R：(1,0,0) 剪切后不动，旋转后到 (0,1,0)。我第一次误答成 (0,2,0)，把 H 当成了拉长；H·R 得到 (1,1,0)。两种顺序 det 都是 1：det 只记录体积倍数和是否翻面，不记录形状。det 的用途：负缩放（det = −1）让三角形绕序反转，渲染器必须反过来剔除；某列是另一列的倍数时 det = 0，矩阵线性相关、不能求逆；此外还用于符号面积（光栅化的边函数）、射线和三角形求交、检测物理模拟里的单元被挤翻。（法线方向、det 的用途是 AI 讲的；补充题我都答对了。）

      What the review taught me: (My code matches the reference, so the questions did the judging.) fromColumns stores the three columns vertically; stored by rows, mulVec((1,0,0)) would return row 1 (a.x, b.x, c.x), the whole matrix becomes its transpose, and rotations turn the other way. det = a · (b × c): |b × c| is the base area and its direction is the base's normal (not an "angle", which I got wrong at first); a dotted with the unit normal is the height, so the product is base × height = volume, and the sign tells whether the columns are right-handed. R·H means shear H first, then rotate R: (1,0,0) is unchanged by the shear and rotates to (0,1,0). I first answered (0,2,0), treating H as a stretch; H·R gives (1,1,0). Both orders have det 1: det records only the volume factor and whether there is a flip, not the shape. Uses of det: a negative scale (det = −1) reverses triangle winding, so the renderer must flip culling; when one column is a multiple of another, det = 0, the matrix is linearly dependent and has no inverse; it also gives signed areas (rasterization edge functions), ray–triangle intersection, and detecting inverted elements in physics simulation. (The AI explained the normal direction and the uses of det; I answered every follow-up correctly.)

      Pitfalls常见误区Common mistakes

      • 把行当成列。新 î 是矩阵的第 1 列 (a, c)，不是第 1 行 (a, b)。旋转矩阵写反了就会转成反方向（因为它的转置就是反向旋转）。
      • 乘法顺序读反。A B v 是先 B 后 A。想「先缩放再旋转」，要写 R S，不是 S R。
      • three.js 的存储顺序。Matrix3.set(…) 按行的顺序传参数，但内部数组 elements 是列优先。直接读写 elements 时要注意，这是新手最常见的坑。
      • 以为 det = 0 只是「很小」。det = 0 说明有一个方向被压没了，信息丢失，矩阵没有逆，变换无法撤销。
      • Mixing up rows and columns. The new î is column 1 (a, c), not row 1 (a, b). Write a rotation matrix transposed and it turns the wrong way (its transpose is the reverse rotation).
      • Reading the product backwards. A B v does B first, then A. To scale first and then rotate, write R S, not S R.
      • three.js storage order. Matrix3.set(…) takes arguments in row order, but the internal elements array is column-major. This is the classic trap when reading or writing elements directly.
      • Treating det = 0 as merely "small". det = 0 means a direction was squashed away: information is lost, there is no inverse, and the transform cannot be undone.
