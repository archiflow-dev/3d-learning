Goals学习目标Learning goals

  • 顺序会改变结果，而且有两种读法：M = A · B 表示先做 B、再做 A（从右往左读，物体在固定的世界坐标里移动）。同一个式子也可以从左往右读：先把坐标系做 A，再在新坐标系里做 B。两种读法结果一样。
  • 物体矩阵用 T · R · S：先缩放、再旋转、最后平移。这样缩放沿物体自己的轴，旋转绕物体自己的中心，第三列正好是物体的位置。顺序一乱，就会出现「公转」或剪切。
  • 法线要用 (M⁻¹)ᵀ 变换：法线必须和表面保持垂直。旋转、均匀缩放时直接用 M 没问题；不均匀缩放或剪切时，要用左上 3×3 的逆的转置，再归一化。
  • Order changes the result, and there are two ways to read it: M = A · B means do B first, then A (read right to left: the object moves in a fixed world frame). The same product can be read left to right: first apply A to the coordinate frame, then do B in the new frame. Both readings give the same result.
  • Object matrices are T · R · S: scale first, then rotate, then translate. Scaling then follows the object's own axes, rotation turns about the object's own center, and column 3 is exactly the object's position. Mix up the order and you get an "orbit" or a shear.
  • Normals transform by (M⁻¹)ᵀ: a normal must stay perpendicular to its surface. Rotations and uniform scales can use M directly; non-uniform scales and shears need the inverse transpose of the top-left 3×3, followed by normalizing.

Intuition直觉Intuition

穿袜子再穿鞋，和穿鞋再穿袜子，结果完全不同。变换也一样：「先转 90° 再右移 3」是原地转身后走开；「先右移 3 再转 90°」是走开后绕着原点公转了四分之一圈。

Socks then shoes is not the same as shoes then socks. Transforms are the same: "turn 90°, then move right 3" spins in place and walks off; "move right 3, then turn 90°" walks off and then swings a quarter orbit around the origin.

游戏引擎给每个物体存三样东西：位置、旋转、缩放。它们总是按 T · R · S 拼起来：先在物体自己的原点把它缩放、转好，最后整个搬到位置上。你在 three.js 里改 rotation，物体总是「原地转」，原因就是这个顺序。

A game engine stores three things per object: position, rotation and scale. They are always combined as T · R · S: scale and turn the object around its own origin, then carry the whole thing to its position. That order is why changing rotation in three.js always spins the object in place.

法线是个特例。把一个圆压扁成椭圆，表面上的切线跟着被压扁；可法线如果也跟着被压扁，就不再垂直于表面了。法线要「反着」变：表面在 x 方向拉长 2 倍，法线的 x 分量反而要缩小一半。

Normals are the special case. Squash a circle into an ellipse and the tangents along its edge get squashed too; if the normals were squashed the same way they would no longer be perpendicular to the surface. Normals must change the opposite way: stretch the surface ×2 along x and the normal's x-component must shrink by half.

The last formula reuses the cross product from lesson 1.3 and det from lesson 1.5: b × c is perpendicular to both b and c, so a · (b × c) = det while b · (b × c) = c · (b × c) = 0. That is exactly what "inverse times matrix = identity" requires.

Why为什么法线要用逆转置？Why do normals need the inverse transpose?

1. 几何：把圆压扁，看法线（拖动滑块）

1. Geometry: squash a circle and watch the normals (move the sliders)

单位圆上每一点的法线就是这个点本身的方向。用 M 把圆变成椭圆，再用两种办法变换法线：玫红色直接用 M，绿色用 (M⁻¹)ᵀ。灰色短线是该点的切线（表面方向）。拉大 sx 或加一点剪切，玫红色很快就不垂直了，绿色始终垂直。

On the unit circle, the normal at each point is the point's own direction. Turn the circle into an ellipse with M and transform the normals two ways: magenta uses M directly, green uses (M⁻¹)ᵀ. The short gray lines are the tangents (the surface direction). Increase sx or add some shear and the magenta normals quickly stop being perpendicular, while the green ones always are.

2. 代数：垂直这件事必须保住

2. Algebra: perpendicularity must survive

切线 t 在表面上，法线 n 垂直于它：nᵀ t = 0。变换后切线变成 A t（它就是表面上两点之差，按方向变换）。我们要找一个矩阵 N，让 (N n)ᵀ (A t) = 0 对所有 t 成立。展开：nᵀ Nᵀ A t = 0。只要 Nᵀ A = I，就变回原来的 nᵀ t = 0，所以 Nᵀ = A⁻¹，N = (A⁻¹)ᵀ。

A tangent t lies in the surface and the normal n is perpendicular to it: nᵀ t = 0. After the transform the tangent becomes A t (it is a difference of two surface points, transformed as a direction). We want a matrix N with (N n)ᵀ (A t) = 0 for every t. Expand: nᵀ Nᵀ A t = 0. If Nᵀ A = I this is the original nᵀ t = 0, so Nᵀ = A⁻¹ and N = (A⁻¹)ᵀ.

什么时候 N 就等于 A？旋转 R 满足 R⁻¹ = Rᵀ，所以 (R⁻¹)ᵀ = R。均匀缩放 k·I 的逆转置是 (1/k)·I，只差一个倍数，归一化后方向一样。所以只有旋转加均匀缩放时，「直接用 M」才碰巧没错。对 A = R · S，(A⁻¹)ᵀ = (S⁻¹ R⁻¹)ᵀ = (R⁻¹)ᵀ (S⁻¹)ᵀ = R · S⁻¹：旋转照旧，缩放取倒数。

When is N just A? A rotation satisfies R⁻¹ = Rᵀ, so (R⁻¹)ᵀ = R. A uniform scale k·I has inverse transpose (1/k)·I, which differs only by a factor, so the direction is the same after normalizing. That is why "just use M" happens to work only for rotations plus uniform scales. For A = R · S, (A⁻¹)ᵀ = (S⁻¹ R⁻¹)ᵀ = (R⁻¹)ᵀ (S⁻¹)ᵀ = R · S⁻¹: same rotation, reciprocal scale.

3. 物理：法线是「每米变化多少」

3. Physics: a normal measures "change per meter"

表面可以看成一个函数 f(x, y) = 0 的等值线，法线就是 f 的梯度 ∇f，也就是「往哪个方向走，f 变得最快，每米变多少」。想象一张温度地图：每隔 1 米温度升高 1 度。把地图在 x 方向拉长 2 倍，同样的温差现在分布在 2 米上，梯度的 x 分量就变成每米 0.5 度。

A surface can be seen as the level set f(x, y) = 0 of a function, and its normal is the gradient ∇f: the direction in which f grows fastest, and by how much per meter. Picture a temperature map that rises 1 degree per meter. Stretch the map ×2 along x and the same temperature difference is now spread over 2 meters, so the gradient's x-component becomes 0.5 degree per meter.

普通方向（速度、切线）的单位是「米」，拉长空间它就跟着变长；法线的单位是「每米」，拉长空间它反而变短。所以一个乘 S，一个乘 S⁻¹。物理里这两类量分别叫向量和余向量（covector）。

An ordinary direction (a velocity, a tangent) is measured in meters, so stretching space makes it longer; a normal is measured in "per meter", so stretching space makes it shorter. One gets multiplied by S, the other by S⁻¹. Physics calls these two kinds of quantities vectors and covectors.

static compose(t, theta, s) {      // 最右边的 S 最先做 / the rightmost S happens first
  return Mat4.translation(t.x, t.y, t.z).mul(Mat4.rotationZ(theta)).mul(Mat4.scaling(s.x, s.y, s.z));
}
normalMatrix() {
  const m = this.m;
  const a = new Vec3(m[0], m[4], m[8]), b = new Vec3(m[1], m[5], m[9]), c = new Vec3(m[2], m[6], m[10]);
  const det = a.dot(b.cross(c));
  const p = b.cross(c).scale(1 / det), q = c.cross(a).scale(1 / det), r = a.cross(b).scale(1 / det);
  return new Mat4([p.x, q.x, r.x, 0,  p.y, q.y, r.y, 0,  p.z, q.z, r.z, 0,  0, 0, 0, 1]);   // p, q, r 是列 / are columns
}
transformNormal(n) { return this.normalMatrix().transformDirection(n).normalize(); }

      Pitfalls常见误区Common mistakes

      • 按执行顺序从左往右写。「先缩放、再旋转、再平移」写成矩阵是 T · R · S，不是 S · R · T。写的顺序和执行顺序相反。
      • 先旋转再做不均匀缩放。S · R（先转后缩放）会让直角变斜，也就是剪切。这样的矩阵拆不回位置、旋转、缩放三样，three.js 的 decompose 也会给出错的结果。
      • 法线直接乘模型矩阵。只有旋转和均匀缩放时碰巧对。three.js 用 Matrix3.getNormalMatrix(matrix4) 计算逆转置，着色器里的 normalMatrix 也是这样来的。
      • 法线变换后忘了归一化。逆转置会改变长度，光照公式需要单位法线（1.2 课的点积）。
      • 把平移也放进法线矩阵。法线是方向，w = 0，只用左上 3×3。
      • Writing the steps left to right in execution order. "Scale, then rotate, then translate" is the matrix T · R · S, not S · R · T. Written order is the reverse of execution order.
      • Rotating before a non-uniform scale. S · R (rotate, then scale) bends right angles, which is a shear. Such a matrix cannot be split back into position, rotation and scale, and three.js's decompose gives wrong results for it.
      • Multiplying normals by the model matrix. It only happens to work for rotations and uniform scales. three.js computes the inverse transpose with Matrix3.getNormalMatrix(matrix4), which is also where the shader's normalMatrix comes from.
      • Forgetting to normalize the transformed normal. The inverse transpose changes length, and lighting needs unit normals (the dot product from lesson 1.2).
      • Putting the translation into the normal matrix. A normal is a direction with w = 0; use only the top-left 3×3.

      Quiz自测Self-check

      1. 点 (1, 0)。M₁ = T(2, 0) · R(90°)，M₂ = R(90°) · T(2, 0)。它分别被送到哪里？1. The point (1, 0). M₁ = T(2, 0) · R(90°), M₂ = R(90°) · T(2, 0). Where does each send it?

      M₁：先转到 (0, 1)，再平移到 (2, 1)。M₂：先平移到 (3, 0)，再绕原点转到 (0, 3)。

      M₁: turn to (0, 1), then move to (2, 1). M₂: move to (3, 0), then turn about the origin to (0, 3).

      2. S = diag(3, 1)。一条表面切线是 (1, 1)，法线是 (1, −1)。直接用 S 变换法线得到什么？还垂直吗？正确答案是什么？2. S = diag(3, 1). A surface has tangent (1, 1) and normal (1, −1). What does S do to the normal, is it still perpendicular, and what is right?

      切线变成 (3, 1)。S · n = (3, −1)，(3, 1) · (3, −1) = 8 ≠ 0，不垂直。正确的是 (S⁻¹)ᵀ n = (1/3, −1)，方向同 (1, −3)，(3, 1) · (1, −3) = 0。

      The tangent becomes (3, 1). S · n = (3, −1), and (3, 1) · (3, −1) = 8 ≠ 0: not perpendicular. The right one is (S⁻¹)ᵀ n = (1/3, −1), the same direction as (1, −3), and (3, 1) · (1, −3) = 0.

      3. 物体矩阵 M = T · R · S。它的逆 M⁻¹ 怎么写？（第 2 阶段的相机矩阵就是这样求的）3. An object matrix is M = T · R · S. How do you write M⁻¹? (Stage 2's camera matrix is computed this way.)

      M⁻¹ = S⁻¹ · R⁻¹ · T⁻¹ = S(1/sx, 1/sy, 1/sz) · R(−θ) · T(−t)。撤销要倒着来：先撤销最后做的平移，再撤销旋转，最后撤销缩放。

      M⁻¹ = S⁻¹ · R⁻¹ · T⁻¹ = S(1/sx, 1/sy, 1/sz) · R(−θ) · T(−t). Undo in reverse: undo the last step (translation) first, then the rotation, then the scale.
